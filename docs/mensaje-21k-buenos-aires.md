# Mensaje para la Media Maratón de Buenos Aires (21K)

> Creado: 20/08/2026. Para postear antes del domingo — el ángulo es
> que la carrera en sí es solo la excusa: el logro real ya se hizo en
> los meses de entrenamiento previo. "Huella" aparece recién sobre el
> final, como guiño a la marca sin forzarlo antes.

## Versión larga

```
Este domingo se largan los 21K de Buenos Aires. Muchos de ustedes van
a estar ahí.

Antes de que arranque, les queremos decir algo: la carrera ya la
corrieron. Se corrió en cada madrugada con frío que salieron igual, en
los rodajes que nadie vio, en las lesiones que superaron.

El domingo no define nada nuevo — muestra algo que ya estaba
construido hace meses.

No vayan pensando en el reloj. La llegada es solo la excusa para que
el resto vea lo que ustedes ya sabían: que lo lograron.

Y cuando crucen la meta, no piensen que ahí termina algo. Piensen en
todo lo que construyeron para llegar hasta ese punto. Esa es su
huella.

Mucha suerte a todos. Disfrútenla.
```

## Versión corta

```
Este domingo, muchos de ustedes corren los 21K de Buenos Aires.
La carrera ya la corrieron: en cada madrugada, en cada rodaje que
nadie vio.
El domingo solo la muestra.
Esa es su huella. Mucha suerte, disfrútenla.
```

## Para los que no corren esta carrera puntual (pero entrenan igual ese día)

```
Y si este domingo no corrés los 21K pero salís a entrenar igual, como
cualquier otro día: esto también es para vos. No hace falta un dorsal
para que cuente. Buen rodaje, buena huella.
```
